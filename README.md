# SUVR

> **Fork of [Erdnusschokolade/stereonaut](https://github.com/Erdnusschokolade/stereonaut).**
> SUVR keeps the original Steam Frame VR video player and adds a localized
> interface, a WebDAV network source and a reusable on-screen keyboard. See
> [What this fork adds](#what-this-fork-adds) for the full list of changes;
> everything below documents the base player.

> [!CAUTION]
> **If you start a video and only see passthrough (no picture), hold the
> recenter button to reset your position** and the video appears. This is a
> known passthrough quirk; it is harmless and not currently a problem.

> [!WARNING]
> **All code in this repository was generated by AI** (Claude by Anthropic and
> Codex by OpenAI) and has **not been reviewed by a human**. It was only
> tested in practice on one Steam Frame. Read and review it before you build,
> run or reuse any of it; use it at your own risk.

## What this fork adds

Relative to upstream `stereonaut`:

- **WebDAV network source.** A dedicated WebDAV page in the side rail: add
  servers from inside the headset (URL, optional user and password), browse
  them (PROPFIND, `Depth: 1`) and play `.mp4`/`.mkv` files straight from the
  server. Playback reuses the existing http(s) pipeline; Basic-auth
  credentials travel in a request header, never on the command line.
  Servers are stored in `~/.config/stereonaut/webdav.json`. A bare
  `host:port` is accepted and defaulted to `http://`.
- **WebDAV thumbnails.** Tile pictures for remote videos: a key frame is
  streamed over http(s) with Basic auth, decoded in software and cached
  under `~/.cache/stereonaut/thumbs`.
- **Multi-language interface.** All interface and error text moved out of
  hard-coded German into translation keys loaded from `src/player/lang/`
  (`eng`, `deu`, `ita`), with the language selectable in the headset from the
  Options rail. English is the default.
- **Reusable on-screen keyboard.** The search keyboard became a general tool
  that can be pointed at any field (search, WebDAV URL/user/password). It
  gained a **Shift** (uppercase) key and a **symbols layer** with
  URL-friendly punctuation, and dropped the German-only characters
  (`ß ü ö ä`).
- **Bug fixes.** Interface and error messages that were German are now
  English/translatable; the headset no longer stays in passthrough until a
  SteamVR recenter when a video starts (the dome recenters on the first
  frame); closing a WebDAV video returns to the folder it was played from
  instead of an empty page.

- **One-file installer.** `src/player/make-selfinstall.sh` builds everything
  and packs the binaries, shaders, language files and a source copy into a
  single self-extracting `SUVR-install.run` (makeself style: a shell stub
  followed by a gzip tarball). Running `sh SUVR-install.run` on the headset
  installs into `~/.local` (binaries, shaders, languages, desktop entry) and
  keeps the source copy the launcher uses to rebuild itself after a SteamOS
  library bump — no compiler needed on the target for a normal install.

The sections below are from the upstream project and describe the base player.

A native VR video player for the **Steam Frame** (SteamOS, aarch64,
Snapdragon 8 Gen 3), that also runs as a PCVR app on Linux with SteamVR. It
plays 180°, 360°, fisheye and flat videos in mono,
side-by-side or top-bottom stereo, from local files or a Jellyfin server, up
to 8K60 – decoded entirely in hardware.

Plain C11, no engine and no software video decoder:

```text
MKV/MP4 -> libavformat (hevc_/h264_mp4toannexb)
        -> HEVC Main 8 | H.264 8 bit 4:2:0 | HEVC Main10 (patched Turnip only)
        -> Iris V4L2 stateful decoder -> NV12/TP10 DMA-BUF
        -> Vulkan YCbCr import -> OpenXR (SteamVR)
Audio:  libavcodec/libswresample -> 48 kHz S16 stereo -> ALSA (master clock)
```

This is a personal project, not affiliated with Valve. It targets the Steam
Frame specifically and has not been tried on other headsets.

## Features

- Browser for local folders and Jellyfin libraries (Quick Connect login,
  thumbnails, sorting, filters by genre/studio/person, search with an
  on-screen keyboard, "continue watching", resume prompt).
- Jellyfin Direct Play for the formats above, server transcoding to HEVC
  Main 8 for everything else, playback reporting and trickplay previews on
  the seek bar.
- Room-fixed playback panel: seek bar with chapter marks, ±10 s, volume,
  end action (stop/repeat/next), auto-hide. Seeks jump to a keyframe within
  the running session, typically in 0.15 to 0.6 s over Jellyfin.
- Per-title projection, stereo layout, eye swap, position, 6DoF head motion
  and picture adjustments; automatic detection of projection and stereo
  layout from file names, Jellyfin trickplay or the first decoded frames.
- Eye-tracked autofocus for close subjects (stereo disparity measured on the
  GPU) with threshold, hysteresis and fade.
- Controller bindings with button combinations, assignable in the headset.
- Experimental, off by default: AV1 (8 bit, up to 4096×2160) decoded on the
  CPU with dav1d, since the shipped kernel exposes no AV1 hardware decoder.

## Building

The code is built on the Steam Frame itself or on Linux with a PCVR OpenXR
runtime. It needs `pkg-config` for
libavformat, libavcodec, libavutil, libswresample, alsa, libcurl, json-c,
freetype2 and libjpeg, plus `glslc`, Vulkan and an OpenXR loader. On the
Frame the bundled SteamVR loader is used; elsewhere the build uses the normal
`pkg-config` OpenXR loader (override either with `OPENXR_LOADER`). All builds
use `-std=c11 -O2 -Wall -Wextra -Werror`.

On a PC (no Iris decoder present) the GPU decodes H.264, HEVC and AV1 with 8
or 10 bits through FFmpeg: CUDA/NVDEC on NVIDIA, otherwise Vulkan Video or
VA-API. Each frame is downloaded into shared memory that the renderer copies
into a device-local image. Tested on an RTX 4080 up to 8192×4096 at 60 fps
(HEVC 8/10 bit, AV1 10 bit) with SteamVR, in the headset with the Steam
Frame streaming from the PC. The panels are drawn into the eye images there,
since SteamVR on a PC shows quad layers with shimmering text. PC controller
profiles (Index, Touch, Windows Mixed Reality, Vive, Cosmos) are suggested
to the runtime.

```sh
src/player/build-stereonaut-session.sh   # session, renderer (XR host), launcher, shaders
src/player/install-user-launcher.sh      # installs to ~/.local/lib/stereonaut and ~/.local/bin
src/player/register-steamvr-app.sh       # once: adds "Stereonaut" to the SteamVR library
```

HEVC Main10 needs a Turnip (Mesa) build with TP10 texture formats; see
`tools/mesa-tp10/` and `docs/main10-linear-output.md`. Without it, Main10 is
rejected locally and transcoded by Jellyfin.

The installer also keeps a copy of the sources in
`~/.local/share/stereonaut/source`. If a SteamOS update removes a library the
installed binaries were linked against (a new major version), the launcher
notices it at start, asks in a dialog (visible in the headset) and rebuilds
and reinstalls itself in about half a minute. The TP10 Turnip is not rebuilt;
if its libraries are missing it is disabled for that start.

The Jellyfin connection is stored in `~/.config/stereonaut/jellyfin.json`
(created by the Quick Connect login in the browser).

The panel layout can be checked on a desktop without a headset:
`src/player/build-ui-preview.sh`, then `build/ui-preview out.ppm` or
`build/ui-preview --player out.ppm`.

## Layout

- `src/player/` – the player: launcher, XR host (`stereonaut-renderer.c`,
  browser and playback panels), per-title session (`stereonaut-session.c`,
  Iris V4L2 state machine), media layer, Jellyfin client. See
  `src/player/README.md`.
- `tools/` – probes and research tools for the decoder, Vulkan/OpenXR and
  Main10; not part of the player.
- `docs/` – measurements and findings from the hardware investigation
  (Iris V4L2, Vulkan import, Q10C/TP10 Main10, projection, OpenXR), mostly in
  German. `docs/mvp-player-status.md` summarises the current state.
  Development plans and task descriptions are not part of this repository;
  some documents still mention them by name.
- `tests/` – generated decoder fixtures (see
  `tools/decoder-probe/generate-fixtures.py`).
